## 2. 2유형 — 템플릿 (분류, 확률 제출)
```python
import pandas as pd
train = pd.read_csv('train.csv'); test = pd.read_csv('test.csv')
y = train['target']; X = train.drop(columns=['ID','target']); X_test = test.drop(columns=['ID'])

num = X.select_dtypes('number').columns; cat = X.select_dtypes('object').columns
for c in num: m = X[c].median(); X[c] = X[c].fillna(m); X_test[c] = X_test[c].fillna(m)
for c in cat: m = X[c].mode()[0]; X[c] = X[c].fillna(m); X_test[c] = X_test[c].fillna(m)

from sklearn.preprocessing import LabelEncoder
for c in cat:
    le = LabelEncoder().fit(pd.concat([X[c], X_test[c]]))
    X[c] = le.transform(X[c]); X_test[c] = le.transform(X_test[c])

from sklearn.model_selection import train_test_split
from sklearn.ensemble import RandomForestClassifier
from sklearn.metrics import roc_auc_score
X_tr, X_val, y_tr, y_val = train_test_split(X, y, test_size=0.2, random_state=0)
model = RandomForestClassifier(n_estimators=300, max_depth=8, random_state=0).fit(X_tr, y_tr)
print(roc_auc_score(y_val, model.predict_proba(X_val)[:,1]))

model.fit(X, y)
pred = model.predict_proba(X_test)[:,1]        # 라벨이면 model.predict(X_test)
pd.DataFrame({'ID': test['ID'], 'pred': pred}).to_csv('result.csv', index=False)
print(pd.read_csv('result.csv').head(), pd.read_csv('result.csv').shape)
```
- 회귀: `RandomForestRegressor`, `model.predict`, RMSE = `mean_squared_error(y, p) ** 0.5`
- 지표 ↔ 제출: **AUC → 확률** / **F1·acc → 라벨** / 회귀 → 숫자
- 다중분류 F1: `f1_score(y, p, average='macro')`

## 3. 3유형 — 상황 → 함수
```python
from scipy import stats
from statsmodels.formula.api import ols, logit
```
| 상황 | 함수 |
|---|---|
| 한 집단 평균 vs 값 | `stats.ttest_1samp(x, 값, alternative='two-sided'/'greater'/'less')` |
| 두 독립 집단 | `stats.ttest_ind(a, b, equal_var=True/False)` |
| 전/후 대응 | `stats.ttest_rel(before, after)` |
| 3집단 이상 | `stats.f_oneway(a, b, c)` |
| 범주 × 범주 독립 | `stats.chi2_contingency(pd.crosstab(a, b))` → chi2, p, dof, expected |
| 비율 적합도 | `stats.chisquare(obs, f_exp=exp)` |
| 정규성 | `stats.shapiro(x)` |
| 등분산 | `stats.levene(a, b)` |
| 상관 | `stats.pearsonr(x, y)`, `stats.spearmanr(x, y)` |
| 비모수 | `mannwhitneyu`, `wilcoxon`, `kruskal` |
| 회귀 | `m = ols('y ~ x1 + x2 + C(cat)', data=df).fit()` |
| 로지스틱 | `m = logit('y ~ x1 + x2', data=df).fit()` |

회귀 결과: `m.params['x1']`, `m.pvalues['x1']`, `m.rsquared`, `m.rsquared_adj`, `m.conf_int().loc['x1']`, `m.predict(pd.DataFrame({...}))`, `m.resid`, `m.fvalue`, `m.f_pvalue`
로지스틱: 오즈비 `np.exp(m.params['x1'])`, 잔차이탈도 `-2*m.llf`, 확률 `m.predict(new)`
신뢰구간: `stats.t.interval(0.95, df=n-1, loc=x.mean(), scale=stats.sem(x))`
분포: `stats.norm.cdf/ppf`, `stats.binom.pmf/cdf(k, n, p)`, `stats.poisson.pmf(k, mu)`
