# 실습 환경 설정 가이드 (Windows)

아나콘다 없이 **순정 Python + VS Code** 로 가볍게 구성합니다.
시험 환경도 Jupyter가 아닌 "웹 코드 에디터 + 실행 버튼" 형태이므로, 이 구성이 오히려 실전과 비슷합니다.

---

## 1. Python 설치

1. https://www.python.org/downloads/windows/ 접속
2. **Python 3.11.x** 또는 **3.12.x** 의 "Windows installer (64-bit)" 다운로드
   - 최신 3.13도 되지만, 패키지 호환성이 가장 안정적인 3.11/3.12 추천
3. 설치 화면 **맨 아래 "Add python.exe to PATH" 체크박스를 반드시 체크** 한 뒤 Install Now
4. 설치 확인: 시작 메뉴 → `cmd` 실행 →
   ```
   python --version
   ```
   `Python 3.11.x` 처럼 나오면 성공. `'python'은(는) 내부 또는 외부 명령...` 이 나오면 PATH 체크를 빠뜨린 것 → 재설치.

## 2. VS Code 설치

1. https://code.visualstudio.com/ → Download for Windows → 설치 (기본값으로 Next)
2. VS Code 실행 → 왼쪽 확장(Extensions, 네모 4개 아이콘) → 아래 두 개 설치
   - **Python** (Microsoft)
   - **Jupyter** (Microsoft)
   - (선택) **Korean Language Pack** – 메뉴 한글화

## 3. 가상환경 + 패키지 설치 (자동)

`D:\my_study\빅분기_실기\01_환경설정\setup.bat` 을 **더블클릭** 하면
- `D:\my_study\빅분기_실기\.venv` 가상환경 생성
- `requirements.txt` 의 패키지 설치
가 자동으로 진행됩니다. 1~3분 걸립니다.

수동으로 하려면 cmd에서:
```
cd /d D:\my_study\빅분기_실기
python -m venv .venv
.venv\Scripts\activate
pip install -r 01_환경설정\requirements.txt
```

## 4. VS Code에서 폴더 열기 & 인터프리터 선택

1. VS Code → File → Open Folder → `D:\my_study\빅분기_실기`
2. `Ctrl+Shift+P` → `Python: Select Interpreter` → `.venv` 가 붙은 항목 선택
   (예: `Python 3.11.x ('.venv': venv)`)
3. `01_환경설정\환경확인.py` 열고 오른쪽 위 ▶ 실행 → 모든 패키지 버전이 출력되면 완료

## 5. 셀 단위 실행 (Jupyter처럼 쓰기)

실습 파일은 `# %%` 주석으로 셀이 나뉘어 있습니다.
- 셀 위에 뜨는 **Run Cell** 클릭, 또는 커서를 셀 안에 두고 `Shift+Enter`
- 오른쪽에 "Interactive Window" 가 열리면서 결과가 표시됩니다
- 변수는 계속 살아있으므로 위에서부터 차례로 실행하면 됩니다

진짜 `.ipynb` 노트북을 쓰고 싶으면: VS Code에서 `Ctrl+Shift+P` → `Create: New Jupyter Notebook`.

## 6. 시험 환경과 똑같이 연습하는 방법 (중요)

실제 시험은
- 웹 브라우저 안의 코드 에디터 (자동완성 없음, 색상 강조 정도만)
- "실행" 버튼 → 아래에 print 결과만 표시
- 인터넷·외부 자료 불가, `help()` / `dir()` 사용 가능

이므로 실력이 어느 정도 붙으면:
1. VS Code 설정에서 자동완성을 꺼보기: `Ctrl+,` → 검색 `Quick Suggestions` → 모두 off
2. 셀 실행 대신 **파일 전체를 ▶ 로 실행하고 print 결과만 보기**
3. 모르는 함수는 구글 대신 `help(pd.DataFrame.groupby)` 로 찾아보기

이 세 가지를 모의고사 때 지켜보세요. 시험장에서 당황하지 않습니다.

## 자주 생기는 문제

| 증상 | 해결 |
|---|---|
| `pip` 가 안 됨 | `python -m pip install ...` 으로 실행 |
| VS Code에서 `import pandas` 에 빨간 줄 | 인터프리터를 `.venv` 로 선택했는지 확인 (4번) |
| 한글 깨짐 (csv) | `pd.read_csv('파일.csv', encoding='cp949')` 또는 `'utf-8-sig'` |
| `# %%` 셀 실행 버튼이 안 보임 | Jupyter 확장 설치 확인, 파일 저장 후 다시 열기 |
| setup.bat 이 바로 닫힘 / 깨진 글자 에러 | setup.bat 은 영문 전용으로 작성됨. 메모장 등으로 수정할 경우 반드시 ANSI 또는 영문만 사용 (한글 UTF-8 저장 시 cmd 가 못 읽음) |
