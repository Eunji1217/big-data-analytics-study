# 05. 모델 평가지표

2유형 채점은 "지표 값이 어느 구간이냐" 로 부분 점수가 매겨집니다. 지표를 이해하면 어떤 값을 제출해야 하는지(확률/라벨)도 명확해집니다.

## 1. 분류 지표

### 혼동행렬 (Confusion Matrix)

|  | 예측 Positive(1) | 예측 Negative(0) |
|---|---|---|
| **실제 Positive(1)** | TP (맞춤) | FN (놓침, 2종 오류) |
| **실제 Negative(0)** | FP (오탐, 1종 오류) | TN (맞춤) |

```python
from sklearn.metrics import confusion_matrix
confusion_matrix(y_true, y_pred)   # [[TN, FP], [FN, TP]] 순서 주의!
```

### 지표 공식

| 지표 | 공식 | 의미 | 언제 |
|---|---|---|---|
| 정확도 Accuracy | (TP+TN) / 전체 | 전체 중 맞춘 비율 | 클래스 균형일 때 |
| 정밀도 Precision | TP / (TP+FP) | 1이라고 한 것 중 진짜 1 | 오탐 비용 클 때 (스팸) |
| 재현율 Recall (민감도) | TP / (TP+FN) | 진짜 1 중 잡아낸 비율 | 놓치면 안 될 때 (암 진단) |
| 특이도 Specificity | TN / (TN+FP) | 진짜 0 중 0이라 한 비율 | |
| F1 | 2 × P × R / (P+R) | 정밀도·재현율 조화평균 | 불균형 데이터 |
| ROC-AUC | ROC 곡선 아래 면적 (0.5 = 랜덤, 1 = 완벽) | 임계값과 무관한 전체 분류 능력 | **확률 제출**, 가장 흔함 |

```python
from sklearn.metrics import accuracy_score, precision_score, recall_score, f1_score, roc_auc_score
accuracy_score(y_val, pred_label)
precision_score(y_val, pred_label)
recall_score(y_val, pred_label)
f1_score(y_val, pred_label)              # 다중분류: average='macro'
roc_auc_score(y_val, pred_proba)         # 확률!  다중: multi_class='ovr'
```

> **ROC-AUC 는 확률(predict_proba)** 을, 나머지는 **라벨(predict)** 을 넣는다. 이걸 헷갈리면 점수가 크게 떨어짐.

### 다중분류에서의 average
- `average='macro'`: 클래스별 지표를 단순 평균 (클래스 균등 취급)
- `average='micro'`: 전체 TP/FP/FN 합쳐서 계산
- `average='weighted'`: 클래스 크기로 가중 평균
문제에 "macro F1" 이라고 나오면 `f1_score(y, pred, average='macro')`.

### 임계값(threshold)
`predict` 는 확률 0.5 기준. 재현율을 올리고 싶으면 `(proba >= 0.3).astype(int)` 처럼 조정 가능. 시험에서는 요구 없으면 기본값.

## 2. 회귀 지표

| 지표 | 공식 | 특징 |
|---|---|---|
| MSE | 평균((실제−예측)²) | 큰 오차에 민감 |
| **RMSE** | √MSE | 단위가 원래 값과 같아 해석 쉬움. **가장 흔함** |
| MAE | 평균(\|실제−예측\|) | 이상치에 덜 민감 |
| MAPE | 평균(\|실제−예측\| / \|실제\|) × 100 | 비율(%) |
| R² (결정계수) | 1 − SSE/SST | 1에 가까울수록 좋음. 0 이하도 가능 |
| RMSLE | √평균((log(1+실제) − log(1+예측))²) | 값 범위 클 때 |

```python
from sklearn.metrics import mean_squared_error, mean_absolute_error, r2_score, root_mean_squared_error
mse  = mean_squared_error(y_val, pred)
rmse = mse ** 0.5                                   # 어떤 버전에서든 동작
# rmse = root_mean_squared_error(y_val, pred)       # sklearn 1.4+ 에서만
mae  = mean_absolute_error(y_val, pred)
r2   = r2_score(y_val, pred)
```

> `mean_squared_error(..., squared=False)` 는 sklearn 1.6에서 **삭제**됨. 시험장 버전을 모르니 `** 0.5` 로 외우는 게 안전.

## 3. 좋은 방향 정리

- **높을수록 좋음**: Accuracy, Precision, Recall, F1, ROC-AUC, R²
- **낮을수록 좋음**: MSE, RMSE, MAE, MAPE, RMSLE

## 4. 검증 점수 해석 감각

- ROC-AUC 0.5 근처 → 뭔가 잘못됨 (타겟 섞임, 확률 대신 라벨 넣음, ID 로 학습 등)
- train 점수 1.0 / valid 0.7 → 과대적합. RandomForest `max_depth=5~10` 정도 제한해 보기
- R² 음수 → 평균으로 찍는 것보다 못함. 전처리/타겟 확인

## 5. 시험용 코드 조각 (검증 단계)

```python
# 분류
from sklearn.metrics import roc_auc_score, f1_score, accuracy_score
proba = model.predict_proba(X_val)[:, 1]
label = model.predict(X_val)
print('AUC :', roc_auc_score(y_val, proba))
print('F1  :', f1_score(y_val, label))
print('ACC :', accuracy_score(y_val, label))

# 회귀
from sklearn.metrics import mean_squared_error, r2_score, mean_absolute_error
pred = model.predict(X_val)
print('RMSE:', mean_squared_error(y_val, pred) ** 0.5)
print('MAE :', mean_absolute_error(y_val, pred))
print('R2  :', r2_score(y_val, pred))
```
