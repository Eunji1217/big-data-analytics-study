실습 파일: `03_실습코드/05_2유형_분류_템플릿.py`, `06_2유형_회귀_템플릿.py`

## 1. 2유형 문제의 전형적인 모습

> "train.csv 로 학습하여 test.csv 의 `구매여부`(0/1)를 예측하시오.
> 예측 **확률** 을 `pred` 컬럼으로, `ID` 와 함께 `result.csv` 로 저장. (평가지표: ROC-AUC)"

- 지도학습(supervised): 정답(타겟)이 있는 데이터로 학습
- **분류(classification)**: 타겟이 범주 (0/1, A/B/C) → 확률 또는 라벨 제출
- **회귀(regression)**: 타겟이 연속형 숫자 (가격, 점수) → 숫자 제출

문제에 나오는 **평가지표 이름을 보면 분류인지 회귀인지 알 수 있음**:
- ROC-AUC, F1, accuracy, precision, recall → 분류
- RMSE, MAE, R², MSE, RMSLE → 회귀

## 2. 전체 흐름 (이 순서를 몸에 익힐 것)

```
1. 데이터 읽기 & 살펴보기        pd.read_csv / info / isnull().sum() / target 분포
2. ID·타겟 분리                  X_train = train.drop(columns=[ID, target]); y = train[target]
3. 결측치 처리                   수치 중앙값 / 범주 최빈값
4. 범주형 인코딩                 LabelEncoder (train+test 합쳐 fit)
5. 검증용 분리                   train_test_split(X, y, test_size=0.2, random_state=0)
6. 모델 학습                     RandomForestClassifier / Regressor
7. 검증 점수 확인                roc_auc_score / f1_score / rmse ...
8. (선택) 전체 train 으로 재학습
9. test 예측 → 제출 파일 저장     pd.DataFrame({'ID':..., 'pred':...}).to_csv('result.csv', index=False)
10. 제출 파일 다시 읽어 확인      pd.read_csv('result.csv').head()
```

## 3. 핵심 개념

### 학습/검증 분리
- 가진 데이터를 train(80%) / valid(20%) 로 나눠 **내 모델이 얼마나 나올지 미리 확인**
- `random_state` 고정 → 실행할 때마다 같은 결과
- `stratify=y` → 분류에서 클래스 비율 유지하며 분리 (불균형 데이터에 유용)

```python
from sklearn.model_selection import train_test_split
X_tr, X_val, y_tr, y_val = train_test_split(X, y, test_size=0.2, random_state=0, stratify=y)
```

### 과대적합 / 과소적합
- **과대적합(overfitting)**: train 점수 높고 valid 점수 낮음. 모델이 train 을 외움. → 트리 깊이 제한(`max_depth`), 데이터 늘리기, 정규화
- **과소적합(underfitting)**: 둘 다 낮음. 모델이 너무 단순. → 더 복잡한 모델, 변수 추가

### 교차검증 (Cross Validation)
데이터를 k 조각으로 나눠 k 번 학습·검증 후 평균. 더 믿을 만한 성능 추정.
```python
from sklearn.model_selection import cross_val_score
scores = cross_val_score(model, X, y, cv=5, scoring='roc_auc')
print(scores.mean())
```
시험에서는 시간상 `train_test_split` 한 번이면 충분.

### 하이퍼파라미터
사람이 정하는 설정값. RandomForest 의 `n_estimators`(트리 개수), `max_depth`(깊이).
`GridSearchCV` 로 탐색 가능하지만 시험에서는 **기본값 + 약간 조정** 정도로 충분.

## 4. 모델 종류 (개념 + 언제 쓰나)

### 분류 모델

| 모델 | 원리 한 줄 | 특징 | sklearn |
|---|---|---|---|
| 로지스틱 회귀 | 선형식 → 시그모이드 → 확률 | 해석 쉬움, 스케일링 필요 | `LogisticRegression` |
| 결정트리 | if-else 질문을 반복해 분할 | 과대적합 잘 됨 | `DecisionTreeClassifier` |
| **랜덤포레스트** ★ | 결정트리 여러 개를 배깅(bagging)해서 투표 | **기본 선택. 전처리 관대, 성능 안정** | `RandomForestClassifier` |
| 그래디언트 부스팅 | 이전 트리의 오차를 다음 트리가 보정 (boosting) | 성능 좋음, 느림 | `GradientBoostingClassifier`, `XGBClassifier`, `LGBMClassifier` |
| KNN | 가까운 k개 이웃의 다수결 | 스케일링 필수 | `KNeighborsClassifier` |
| SVM | 마진 최대화 초평면 | 스케일링 필수, 느림 | `SVC(probability=True)` |
| 나이브베이즈 | 베이즈 정리 기반 확률 | 텍스트에 강함 | `GaussianNB` |

### 회귀 모델

| 모델 | sklearn |
|---|---|
| 선형회귀 | `LinearRegression` |
| 릿지 (L2 규제) / 라쏘 (L1 규제, 변수선택 효과) | `Ridge`, `Lasso` |
| **랜덤포레스트 회귀** ★ | `RandomForestRegressor` |
| 그래디언트 부스팅 회귀 | `GradientBoostingRegressor`, `XGBRegressor` |

### 앙상블 용어
- **배깅(Bagging)**: 데이터를 부트스트랩(복원추출)으로 여러 개 만들어 각각 학습 → 평균/투표. 분산 감소. (랜덤포레스트)
- **부스팅(Boosting)**: 약한 모델을 순차적으로, 이전 오차를 줄이는 방향으로 학습. 편향 감소. (GBM, XGBoost, LightGBM)
- **보팅(Voting)**: 서로 다른 모델의 예측을 투표/평균. `VotingClassifier`
- **스태킹(Stacking)**: 여러 모델 예측을 다시 메타모델 입력으로.

## 5. 시험용 모델 선택 원칙

1. **RandomForest 로 시작** (`n_estimators=200~500, random_state=0`) — 대부분 만점 구간 진입
2. 시간 남으면 `GradientBoosting` 이나 `XGBoost` 한 번 돌려 valid 점수 비교
3. 점수 더 좋은 쪽으로 제출
4. 로지스틱회귀는 스케일링 + 원핫 필요해서 손이 많이 감 → 백업용

## 6. predict vs predict_proba (매우 중요)

```python
model.predict(X_test)              # 라벨 (0 또는 1)          → 지표가 accuracy, F1 일 때
model.predict_proba(X_test)[:, 1]  # 1일 확률 (0.0~1.0)       → 지표가 ROC-AUC 일 때
```
- `predict_proba` 결과는 (n, 클래스수) 2차원 → `[:, 1]` 로 두 번째 열(=1 확률)
- 문제가 "확률을 제출" 이면 `predict_proba`, "0/1 을 제출" 이면 `predict`. **ROC-AUC 채점인데 predict 를 내면 점수 크게 손해.**
- 다중분류(A/B/C)에서는 `predict` 로 라벨 제출이 보통.

## 7. 제출 파일 규칙

```python
result = pd.DataFrame({'ID': test['ID'], 'pred': pred})
result.to_csv('result.csv', index=False)          # index=False 안 쓰면 컬럼 하나 더 생겨 0점 가능
print(pd.read_csv('result.csv').head())            # 반드시 확인
print(pd.read_csv('result.csv').shape)             # test 행 수와 같아야 함
```
- 컬럼명·파일명은 **문제 지시 그대로** (대소문자까지)
- ID 컬럼을 포함하라고 하면 포함, 하지 말라면 pred 만

## 8. 자주 하는 실수

1. 타겟 컬럼을 X 에서 안 빼거나, ID 컬럼을 X 에 넣어둠 (ID 넣으면 성능 하락)
2. test 에는 타겟 컬럼이 **없음** — train 과 컬럼 구성이 다르다는 걸 잊음
3. 인코딩을 train 만 하고 test 안 함 → `could not convert string to float` 에러
4. train/test 인코딩을 따로 fit → 같은 범주가 다른 숫자로 매핑
5. `predict_proba` 에서 `[:, 1]` 안 붙임 → 2열이 저장됨
6. `index=False` 누락
7. 검증 데이터(X_val)로 최종 예측 → test 로 해야 함. 행 수 확인으로 잡힘.
