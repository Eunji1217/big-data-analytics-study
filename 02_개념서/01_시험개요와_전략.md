## 3. 유형별 전략

### 1유형 (30점) — "pandas 문법 싸움"
- 문제 예: "결측치가 있는 행을 제거한 뒤, A컬럼 상위 10개의 B컬럼 평균을 정수로 출력"
- 문제를 **단계별로 쪼개서** 한 줄씩 print로 확인하며 진행
- 자주 나오는 것: 정렬/상위 N개, groupby 집계, 결측치 처리, 이상치(IQR), 표준화, 날짜 처리, 문자열 처리, 조건 필터링
- **정답 형식 주의**: 정수? 소수 둘째 자리? `round()`, `int()` 를 문제 지시대로.

### 2유형 (40점) — "템플릿 암기"
- 한 문제이지만 40점. **부분 점수는 성능 지표 구간에 따라** 주어짐 (예: ROC-AUC 0.8 이상 만점 식).
- 완벽한 모델보다 **제출 파일 형식이 맞는 것**이 먼저. 형식 틀리면 0점.
- 흐름: 데이터 확인 → 결측 처리 → 인코딩 → train/valid 분리 → RandomForest → 검증 지표 확인 → 전체 학습 → test 예측 → `to_csv(index=False)`
- 이 흐름을 `03_실습코드/05_2유형_분류_템플릿.py` 로 통째로 손에 익힐 것.

### 3유형 (30점) — "어떤 검정인지 판단 + 함수명 암기"
- 문제 예: "두 집단 평균 차이 검정 → 검정통계량, p값 출력, 유의수준 0.05에서 채택/기각"
- scipy.stats 의 t검정 계열, 카이제곱, ANOVA / statsmodels 의 회귀(OLS), 로지스틱(Logit)
- 소문제 2~3개로 구성되고 각각 답을 print. **소수점 자리수 지시** 를 꼭 따를 것.

## 5. 채점 관련 팁

- 1유형: 출력값 **하나만** print. 중간 확인용 print는 제출 전 지우거나 주석 처리.

- 3유형: `round(값, 자릿수)` 로 자릿수 맞추기. p값이 매우 작으면 `0.0` 으로 나올 수 있음 (정상).
- 모든 유형: 마지막에 **전체 코드 다시 실행해서 에러 없는지 확인**.
