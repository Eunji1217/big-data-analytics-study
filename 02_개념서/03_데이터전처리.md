# 03. 데이터 전처리

실습 파일: `03_실습코드/03_전처리_실습.py`
1유형에서는 "전처리 그 자체"가 문제이고, 2유형에서는 모델링 전 단계로 필요합니다.

## 1. 결측치 (Missing value)

| 방법 | 언제 | 코드 |
|---|---|---|
| 행 제거 | 결측이 적을 때 | `df.dropna(subset=['A'])` |
| 평균/중앙값 대치 | 수치형. 이상치 있으면 **중앙값** | `df['A'].fillna(df['A'].median())` |
| 최빈값 대치 | 범주형 | `df['A'].fillna(df['A'].mode()[0])` |
| 그룹별 대치 | 그룹 특성이 뚜렷할 때 | `df['A'] = df.groupby('g')['A'].transform(lambda x: x.fillna(x.mean()))` |
| 상수 대치 | "없음" 자체가 정보일 때 | `df['A'].fillna('None')` / `fillna(0)` |
| 컬럼 삭제 | 결측 비율 매우 높을 때 | `df.drop(columns=['A'])` |

2유형 기본: 수치형 → 중앙값, 범주형 → 최빈값 (안전하고 빠름).
**train 통계로 test 도 채워야** 하지만 시험에서는 train/test 각각 채워도 큰 문제 없음.

## 2. 이상치 (Outlier)

### IQR 방식 (시험 단골 ★)
```python
Q1 = df['A'].quantile(0.25)
Q3 = df['A'].quantile(0.75)
IQR = Q3 - Q1
lower = Q1 - 1.5 * IQR
upper = Q3 + 1.5 * IQR
outliers = df[(df['A'] < lower) | (df['A'] > upper)]
print(len(outliers))                               # 이상치 개수
df_clean = df[(df['A'] >= lower) & (df['A'] <= upper)]   # 제거
```

### 표준편차 방식
```python
m, s = df['A'].mean(), df['A'].std()
outliers = df[(df['A'] < m - 3*s) | (df['A'] > m + 3*s)]
```

처리 방법: 제거 / 경계값으로 대체(`clip(lower, upper)`) / 그대로 두고 트리 모델 사용(트리는 이상치에 둔감)

## 3. 스케일링 (수치형 변환)

| 방법 | 공식 | sklearn |
|---|---|---|
| 표준화 (Standardization) | (x − 평균) / 표준편차 → 평균 0, 표준편차 1 | `StandardScaler` |
| 정규화 (Min-Max) | (x − min) / (max − min) → 0~1 | `MinMaxScaler` |
| 로버스트 | (x − 중앙값) / IQR, 이상치에 강함 | `RobustScaler` |

```python
from sklearn.preprocessing import StandardScaler, MinMaxScaler
sc = StandardScaler()
df['A_std'] = sc.fit_transform(df[['A']])     # 대괄호 2개 (2D 필요)
# 1유형에서 직접 계산 요구 시
df['A_std'] = (df['A'] - df['A'].mean()) / df['A'].std()
df['A_mm']  = (df['A'] - df['A'].min()) / (df['A'].max() - df['A'].min())
```

> 트리 모델(RandomForest 등)은 스케일링 **불필요**. 로지스틱회귀·SVM·KNN·선형회귀는 필요.
> 2유형에서 RandomForest 를 쓴다면 스케일링은 생략해도 점수 차이 거의 없음.

## 4. 인코딩 (범주형 → 숫자) ★★★

모델은 문자열을 못 받음. 2유형에서 반드시 거치는 단계.

### 라벨 인코딩 (Label Encoding)
범주 → 0,1,2,... 트리 모델에 적합. 가장 간단.
```python
from sklearn.preprocessing import LabelEncoder
le = LabelEncoder()
df['cat'] = le.fit_transform(df['cat'])
```
train/test 나눠져 있을 때 안전한 방법 (test 에 새 범주가 있어도 에러 안 남):
```python
for col in cat_cols:
    all_vals = pd.concat([train[col], test[col]])
    le = LabelEncoder().fit(all_vals)
    train[col] = le.transform(train[col])
    test[col]  = le.transform(test[col])
```

### 원-핫 인코딩 (One-Hot)
범주마다 0/1 컬럼 생성. 선형모델·로지스틱에 적합.
```python
df = pd.get_dummies(df, columns=['cat'])            # 전체
df = pd.get_dummies(df, columns=['cat'], drop_first=True)
# train/test 컬럼 수 맞추기
train_d = pd.get_dummies(train)
test_d  = pd.get_dummies(test)
test_d  = test_d.reindex(columns=train_d.columns, fill_value=0)
```

### map 으로 직접

df['sex'] = df['sex'].map({'male':0, 'female':1})

## 8. 용어 정리 (필기에서도 나온 것들)

- **표본표준편차 vs 모표준편차**: pandas `std()` 는 n−1 (표본), numpy `std()` 는 n (모). 문제에 명시 없으면 pandas 기본.
- **왜도(skewness)**: 분포의 비대칭. 양수면 오른쪽 꼬리. `df['A'].skew()`
- **첨도(kurtosis)**: 분포의 뾰족함. `df['A'].kurt()`
- **불균형 데이터**: 타겟 클래스 비율이 크게 다름. 2유형에서 `class_weight='balanced'` 옵션 정도로 대응 가능.
- **데이터 누수(leakage)**: test 정보가 train 에 새어 들어가는 것. 스케일러·인코더는 train 으로 fit, test 는 transform 만.
