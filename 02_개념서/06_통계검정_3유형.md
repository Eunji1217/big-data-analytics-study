3유형은 **"어떤 상황 → 어떤 검정 → 어떤 함수"** 매핑을 외우고, 출력 형식(반올림·채택/기각)을 지키면 됩니다.

## 1. 가설검정 기본 개념

- **귀무가설 H0**: "차이가 없다 / 효과가 없다 / 독립이다" (기본 입장)
- **대립가설 H1**: "차이가 있다 / 효과가 있다 / 관련 있다" (주장하고 싶은 것)
- **p-value**: H0 가 참일 때 지금 관측된 것(또는 더 극단적인 것)이 나올 확률
- **유의수준 α** (보통 0.05): p < α 이면 **H0 기각** (= 대립가설 채택, "유의한 차이 있음")
- **검정통계량**: t, F, χ², z 등 검정마다 계산되는 값
- **1종 오류**: H0 가 참인데 기각 (α). **2종 오류**: H0 가 거짓인데 채택 (β). 검정력 = 1−β

```python
alpha = 0.05
if p < alpha:
    print('귀무가설 기각')     # 유의한 차이 있음
else:
    print('귀무가설 채택')     # (정확히는 '기각하지 못함')
```

### 단측 vs 양측
- 양측(two-sided): "다르다" (기본값)
- 단측(one-sided): "크다" 또는 "작다". scipy 는 `alternative='greater'` / `'less'`
- 양측 p 를 단측으로 바꾸려면 p/2 (방향 맞을 때)

## 2. 상황 → 검정 매핑표 ★★★ (이 표를 외우세요)

| 상황 | 검정 | 함수 |
|---|---|---|
| 한 집단 평균 vs 특정 값 | 단일표본 t검정 | `stats.ttest_1samp(x, popmean=값)` |
| 두 독립 집단 평균 비교 | 독립표본 t검정 | `stats.ttest_ind(a, b, equal_var=True/False)` |
| 같은 대상의 전/후 비교 | 대응표본 t검정 | `stats.ttest_rel(before, after)` |
| 세 집단 이상 평균 비교 | 일원분산분석 ANOVA | `stats.f_oneway(a, b, c)` |
| 두 범주형 변수의 독립성 | 카이제곱 독립성 검정 | `stats.chi2_contingency(교차표)` |
| 관측 빈도 vs 기대 비율 | 카이제곱 적합도 검정 | `stats.chisquare(관측, 기대)` |
| 정규성 확인 | Shapiro-Wilk | `stats.shapiro(x)` |
| 등분산 확인 | Levene / Bartlett | `stats.levene(a, b)` / `stats.bartlett(a, b)` |
| 두 변수 상관관계 | 피어슨 상관 | `stats.pearsonr(x, y)` |
| 순위 상관 (비모수) | 스피어만 | `stats.spearmanr(x, y)` |
| 두 독립 집단, 정규성 없음 | Mann-Whitney U | `stats.mannwhitneyu(a, b)` |
| 대응 표본, 정규성 없음 | Wilcoxon | `stats.wilcoxon(before, after)` |
| 세 집단 이상, 정규성 없음 | Kruskal-Wallis | `stats.kruskal(a, b, c)` |
| 다중회귀 (계수, p값, R²) | OLS | `ols('y ~ x1 + x2', data=df).fit()` |
| 로지스틱 회귀 (오즈비) | Logit | `logit('y ~ x1 + x2', data=df).fit()` |

```python
from scipy import stats
import statsmodels.api as sm
from statsmodels.formula.api import ols, logit
```

모든 scipy 검정은 `(통계량, p값)` 을 돌려줌:
```python
stat, p = stats.ttest_ind(a, b)
print(round(stat, 4), round(p, 4))
```

## 3. t검정 상세

### 단일표본
"이 반의 평균 키가 170 인가?"
```python
stat, p = stats.ttest_1samp(df['height'], popmean=170)
stat, p = stats.ttest_1samp(df['height'], 170, alternative='greater')   # 170보다 큰가
```

### 독립표본
"남/녀 평균 키가 다른가?"
```python
a = df[df['sex']=='M']['height']
b = df[df['sex']=='F']['height']
stat, p = stats.ttest_ind(a, b)                    # 등분산 가정 (기본)
stat, p = stats.ttest_ind(a, b, equal_var=False)   # 등분산 아님 (Welch)
```
문제에 "등분산을 가정하지 않는다" 가 나오면 `equal_var=False`.

### 대응표본
"약 복용 전/후 혈압이 다른가?"
```python
stat, p = stats.ttest_rel(df['before'], df['after'])
# 단측: after 가 더 작다 = before - after > 0
stat, p = stats.ttest_rel(df['before'], df['after'], alternative='greater')
```

## 4. 분산분석 (ANOVA)
"A/B/C 세 반의 평균이 모두 같은가?"
```python
g = [grp['score'].values for _, grp in df.groupby('class')]
f, p = stats.f_oneway(*g)
# 또는
f, p = stats.f_oneway(df[df['class']=='A']['score'], df[df['class']=='B']['score'], df[df['class']=='C']['score'])
```
statsmodels 로 ANOVA 표 (F, p, 자유도 확인):
```python
from statsmodels.formula.api import ols
import statsmodels.api as sm
model = ols('score ~ C(class_)', data=df).fit()    # 범주형은 C()
print(sm.stats.anova_lm(model))
```
이원분산분석: `ols('y ~ C(A) + C(B) + C(A):C(B)', data=df).fit()` → `anova_lm(model, typ=2)`

## 5. 카이제곱 검정

### 독립성 검정
"성별과 구매여부가 관련 있는가?"
```python
table = pd.crosstab(df['sex'], df['buy'])
chi2, p, dof, expected = stats.chi2_contingency(table)
print(round(chi2, 4), round(p, 4), dof)
```
### 적합도 검정
"주사위 6면이 균등한가? (관측: [10,12,8,11,9,10])"
```python
obs = [10,12,8,11,9,10]
exp = [10]*6                        # 기대빈도 (합이 관측 합과 같아야 함)
chi2, p = stats.chisquare(obs, f_exp=exp)
```

## 6. 회귀분석 (statsmodels) ★★

3유형에서 "회귀계수, p값, R², 신뢰구간, 예측값" 을 물어보는 문제가 많음.

```python
from statsmodels.formula.api import ols
model = ols('y ~ x1 + x2 + x3', data=df).fit()
print(model.summary())                    # 전체 표 (연습용, 시험에선 아래처럼 개별 값)

model.params                # 회귀계수 (Series). model.params['x1']
model.pvalues               # 계수별 p값. model.pvalues['x1']
model.rsquared              # R²
model.rsquared_adj          # 수정 R²
model.fvalue, model.f_pvalue  # 모델 전체 F검정
model.conf_int()            # 95% 신뢰구간 (DataFrame). model.conf_int().loc['x1']
model.conf_int(alpha=0.01)  # 99%
model.resid                 # 잔차
model.predict(pd.DataFrame({'x1':[1], 'x2':[2], 'x3':[3]}))   # 예측
model.bse                   # 표준오차
model.tvalues               # t값
model.aic, model.bic
```

formula 문법:
- `y ~ x1 + x2` : 절편 포함 (기본)
- `y ~ x1 - 1` : 절편 제외
- `y ~ C(cat)` : 범주형 변수 더미화
- `y ~ x1 * x2` : x1 + x2 + x1:x2 (상호작용)
- `y ~ np.log(x1)` : 변환

컬럼명에 공백·특수문자가 있으면 `Q('컬럼 명')` 또는 미리 rename.

sklearn 방식 (계수만 필요할 때):
```python
from sklearn.linear_model import LinearRegression
lr = LinearRegression().fit(df[['x1','x2']], df['y'])
lr.coef_, lr.intercept_
```

## 7. 로지스틱 회귀 (statsmodels)

"흡연 여부가 질병에 미치는 영향, 오즈비를 구하시오"
```python
from statsmodels.formula.api import logit
import numpy as np
model = logit('disease ~ smoke + age', data=df).fit()
model.params                       # 로그 오즈 계수
np.exp(model.params)               # 오즈비(odds ratio). np.exp(model.params['smoke'])
model.pvalues
model.predict(new_df)              # 확률
```
- **오즈** = p / (1−p). **오즈비** = exp(계수). "smoke 가 1 증가할 때 오즈가 exp(β)배"
- 잔차이탈도(deviance) = `-2 * model.llf`, `model.llf` 는 로그우도

sklearn 로지스틱(`LogisticRegression`)은 규제(C)가 기본 적용되어 계수가 statsmodels 와 조금 다름. 3유형에서 "오즈비/p값" 물어보면 statsmodels 사용.

## 8. 정규성·등분산 검정

```python
stat, p = stats.shapiro(df['x'])        # p > 0.05 → 정규성 만족

stat, p = stats.bartlett(a, b)
stat, p = stats.kstest(df['x'], 'norm') # K-S 검정 (표준정규와 비교)
```

## 9. 신뢰구간 (직접 계산)

평균의 95% 신뢰구간 (t분포):
```python
x = df['val']
n = len(x); m = x.mean(); s = x.std(ddof=1)
t = stats.t.ppf(0.975, df=n-1)
lower, upper = m - t*s/np.sqrt(n), m + t*s/np.sqrt(n)
# 또는
stats.t.interval(0.95, df=n-1, loc=m, scale=stats.sem(x))
```

## 10. 확률분포 함수 (가끔 출제)

stats.norm.cdf(x, loc=평균, scale=표준편차)
stats.binom.pmf(k, n, p)         # 이항분포 P(X = k)
