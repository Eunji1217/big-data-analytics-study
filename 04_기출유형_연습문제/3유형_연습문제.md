# 작업형 3유형 연습문제 (모의고사)

## 문제 1. 대응표본 t검정 (`stats_bp.csv`)

혈압약 복용 전(`before`)과 후(`after`)의 혈압을 측정하였다. 복용 후 혈압이 **감소했는지** 유의수준 0.05 에서 검정하시오.

1. 복용 전과 후의 차이(before − after)의 표본 평균을 소수 둘째 자리까지 출력
2. 검정통계량을 소수 넷째 자리까지 출력
3. p-value 를 소수 넷째 자리까지 출력
4. 귀무가설 채택/기각 여부를 '채택' 또는 '기각' 으로 출력

## 문제 2. 독립표본 t검정 (`stats_bp.csv`)

남성(`sex`='M')과 여성('F')의 복용 전 혈압 평균이 다른지 검정하시오.

1. Levene 등분산 검정의 p-value (소수 넷째)
2. 1번 결과에 따라 적절한 t검정(등분산이면 Student, 아니면 Welch)을 수행하여 검정통계량 (소수 넷째)
3. p-value (소수 넷째) 와 채택/기각

## 문제 3. 카이제곱 독립성 검정 (`stats_chi.csv`)

성별(`sex`)과 구매 여부(`buy`)가 독립인지 유의수준 0.05 에서 검정하시오.

1. 남성이면서 구매한('Yes') 관측 빈도 (정수)
2. 위 칸의 기대빈도 (소수 둘째)
3. 카이제곱 통계량 (소수 넷째)
4. p-value (소수 넷째) 와 채택/기각

## 문제 4. 일원분산분석 (`stats_score.csv`)

세 반(`class` A/B/C)의 점수(`score`) 평균이 모두 같은지 검정하시오.

1. 각 반의 평균 중 최댓값 (소수 둘째)
2. F 통계량 (소수 넷째)
3. p-value (소수 넷째) 와 채택/기각

## 문제 5. 다중 선형회귀 (`stats_adv.csv`)

`Sales` 를 종속변수, `TV`, `Radio`, `Newspaper` 를 독립변수로 하는 회귀모형을 적합하시오.

1. `Radio` 의 회귀계수 (소수 넷째)
2. 결정계수 R² (소수 넷째)
3. 유의수준 0.05 에서 유의하지 않은 독립변수의 이름
4. `Radio` 계수의 95% 신뢰구간 상한 (소수 넷째)
5. TV=100, Radio=25, Newspaper=30 일 때 예측 Sales (소수 둘째)

## 문제 6. 로지스틱 회귀 (`stats_disease.csv`)

`disease` (1=질병) 를 종속변수, `smoke`, `age`, `exercise` 를 독립변수로 로지스틱 회귀를 적합하시오.

1. `smoke` 의 오즈비 (소수 셋째)
2. `age` 가 5 증가할 때 오즈비 (소수 셋째)
3. `exercise` 계수의 p-value (소수 넷째) 와 유의 여부
4. 잔차이탈도(residual deviance) (소수 둘째)
5. smoke=1, age=45, exercise=1 인 사람의 질병 확률 (소수 셋째)

## 문제 7. 단일표본 & 정규성 (`stats_score.csv`)

반 A 의 점수가 평균 70 보다 크다고 할 수 있는지 검정하시오.

1. 반 A 점수의 Shapiro-Wilk 정규성 검정 p-value (소수 넷째)
2. 단측 t검정의 검정통계량 (소수 넷째)
3. p-value (소수 넷째) 와 채택/기각
4. 반 A 점수 평균의 95% 신뢰구간 하한 (소수 셋째)
